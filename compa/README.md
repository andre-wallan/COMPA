# COMPA — Your Learning Partner

## Overview

COMPA is a Next.js landing page for a learning platform designed to help students find study resources and build effective learning habits. It introduces a collection of learning tools and describes support for students at different stages of education.

The current project is a frontend prototype: the quizzes, library, videos, AI assistant, study planner, and flashcards are presented as planned platform features, but their interactive functionality is not implemented yet.

## Development Environment

- **Visual Studio Code** — code editor
- **Node.js and npm** — JavaScript runtime and package manager
- **Next.js 16** — React framework using the App Router
- **React 19** — UI library
- **TypeScript** — application language with strict type checking enabled
- **Tailwind CSS 4** — styling

## Features

- **Learning platform landing page** introducing COMPA and its mission
- **Feature overview** for quizzes, a digital library, video learning, an AI study assistant, a study planner, and flashcards
- **Education-level section** for primary school, secondary school, college, and university students
- **Navigation and calls to action** linking to sections of the page
- **Responsive layouts** that adapt across screen sizes

The learning tools listed above describe COMPA's planned offering; they are not yet working application features.

## How to Run

1. Clone the repository and open the `compa` project directory.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

To create and run a production build:

```bash
npm run build
npm start
```
